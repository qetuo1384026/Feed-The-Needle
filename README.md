# Feed The Needle — 3D Fan-Made Recreation

一个受 Steam 免费游戏 **Find The Needle Demo**(Needless Games)公开玩法启发的原创 3D 网页实现。
所有代码、模型与贴图均为本项目原创(程序化生成),不包含原游戏的任何资产。

## 游戏概念

你被困在一间仓库里,面前是一座约 600 万根草的巨型草垛,里面藏着一根针。

- **徒手挖掘**:用铲子从草垛中挖取干草
- **售卖干草**:把干草运到售卖传送带换钱
- **购买升级**:更好的铲子、更大的袋子、金属探测器
- **自动化**:购买自动挖掘机、传送带、打包机,让机器替你干活
- **目标**:清空草垛,找到那根针

## 技术栈

| 组件 | 技术 |
|------|------|
| 3D 渲染 | Three.js (WebGL) |
| 构建工具 | Vite |
| 语言 | JavaScript (ES Modules) |
| 运行环境 | 现代浏览器 |

## 使用说明

```bash
# 安装依赖
npm install

# 开发模式(热更新)
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

打开浏览器访问终端中显示的地址(默认 `http://localhost:5173`)。

## 操作方式

| 按键 | 动作 |
|------|------|
| 鼠标点击画面 | 锁定鼠标指针 |
| W / A / S / D | 移动 |
| 鼠标 | 视角 |
| 左键(对准草垛) | 挖掘 |
| E (对准售卖带) | 出售背负的干草 |
| B | 打开/关闭商店 |
| Esc | 释放鼠标 |
